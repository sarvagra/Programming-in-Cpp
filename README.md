# 🚀 Programming in C++ & Problem Solving

A clean, no-nonsense roadmap of learning **C++ from scratch** and solving **LeetCode problems** step-by-step (with both C++ & Python solutions).

---

## 📂 Repository Structure

```plaintext
Programming-in-Cpp/
├── 📚 Basics/        # C++ Core Concepts (from "Hello World" to Data Structures)
├── ⚡ cpp/           # LeetCode problem solutions written in C++
└── 🐍 python/        # Same LeetCode problems solved in Python (.ipynb notebooks)
```

## 🗺️ What's Inside?

### 1. 📚 `Basics/` — Zero to Hero in C++

* **`00 - 03`** ➔ `Hello World`, Sum, Standard I/O (`cin`, `cout`, `cerr`, `clog`)
* **`04 - 07`** ➔ Execution model, number systems, integer types & variable modifiersf
* **`08 - 10`** ➔ User inputs, Dynamic arrays (`std::vector`), and Static arrays
* **`11 - 12`** ➔ Hash maps (`std::unordered_map`) & Linked Lists with custom node creation

### 2. ⚡ `cpp/` & 🐍 `python/` — Problem Solving & DSA

| #            | Problem         |                                  C++ Solution                                  |                                      Python Notebook                                      | Approach                    |
| ------------ | --------------- | :-----------------------------------------------------------------------------: | :---------------------------------------------------------------------------------------: | --------------------------- |
